## ITM-1264's stop: decided (po-opus-c)

**ITM-1264 is narrowed to `#implement`. The job page is ITM-1305, which waits for a draft of MOD-main-page for akmaier.**

  "besides only the declaration, the declared model's file and the role assignments".
  - To do that without the scope `work`, the page needs `readDocument`, `participantSchema`, `participantsOf`,
    `declarationSchema`, `roleAssignmentSchema`, and `workflowOf` or `productWorkflow`.
  - MOD-main-page's Uses (MOD-main-page.md:26-35) name none of them, and TST-106805 refused the import (run 40836149164).
  - Naming them is a change of the module file, akmaier's.
- **`#implement` and `productWorkflow`.** MOD-implementation-pages' Uses name `MOD-product-process.workflowOf` (:44),
  not `productWorkflow`.
  - TST-106805 lets it pass, since it checks the module before the dot, not the function (sprint 111's ruling on
    ITM-1268).

    with `workflowOf`, from the declared model's file it reads, as `process` does
    (`src/implementation-pages/process.mjs:237-242`).
